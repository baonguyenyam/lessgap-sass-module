# 0024. Public Suffix List — submission recorded, not run in code

**Status:** accepted
**Date:** 2026-10-29

## Context
Tenant sites live at `<slug>.<sites-domain>` — every tenant site is a
subdomain of one suffix. Without a PSL entry, browsers treat the whole
domain as one registrable site: cookies set on one tenant's host could
read on another's.

## Decision
The sites domain (`NEXT_PUBLIC_SITES_DOMAIN` — `lessgap.io` in dev)
goes on the Public Suffix List so each `*.<sites-domain>` is its own
registrable boundary. The submission is a manual step at
publicsuffix.org — the code only needs the domain to be dedicated to
tenant sites (never mixed with the platform's own hostnames).

## Consequences
- Checklist for the submission: dedicated domain, wildcard cert (already
  via the domain provider), a DNS TXT verification entry.
- `RESERVED_SLUGS` keeps `www`, `app`, `api` off the tenant namespace —
  the platform hostnames stay reservable under the same suffix.
- Until the listing lands, cookie-based features on site hosts share
  the registrable domain — noted as a standing caveat in ops docs.
